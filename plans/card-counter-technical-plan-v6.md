# 记牌器计数重构方案 v6：手动新局 + 正数会计 + 手牌差分

更新时间：2026-08-14
状态：待确认（未开始编码）

## 一、一句话结论

停止在识别精度上继续堆砌；先解决会计架构的三个硬缺陷：没有新局边界、自己手牌信号被当装饰、倒数为唯一锚点且永不校准。破局点是**用户长按重置 = 显式开始新局**，把不可靠的自动检测新局换成确定的手动操作。

## 二、现状缺陷（已核实的证据）

1. **没有新局概念（最严重）**：全工程只有会话存储初始化时派发 NewSession，出牌服务从不派发。会计状态跨局永远累加，只有杀进程才清零。真机曾记录单局 98 张已出（>54 张单局上限），证明多局混合累计。
2. **自己手牌是纯装饰**：SelfCardsPlayed 事件只写日志、不更新任何计数（GameReducer.addSelfPlay 为空操作）。自己手牌区每帧可见、是全场最可靠的差分信号，却被浪费。
3. **唯一锚点是一次性锁手牌**：剩余 = 198 - 自己手牌(开局锁一次) - 已出(逐事件累加)。开局锁牌错一次，全盘永久错，无校准机制。
4. **clampTo 掩盖错误**：越界牌被悄悄截断（GameReducer.addOutsidePlay），错误不暴露、不修正。
5. **跨区重复入账**：真机日志有 12 组跨座位间隔 <700ms 的连续入账（最短 68ms），同一轮次被多次记录。

## 三、目标状态

- 用户操作流：开局 -> **长按重置按钮 -> 应用识别自己手牌并锁定 -> 确认新局已开始** -> 会计全部归零 -> 之后每手出牌正数累加。
- 旧记录日志不影响新局（相当于重开，会计从 0 开始）。
- 计数与牌面识别解耦：**数量只来自出牌张数，牌面只影响显示猜测**。
- 守恒校验代替 clamp：所有已出 + 自己剩余 <= 198，违反则暂停/冻结，让错误暴露。

## 四、实现拆解（按依赖顺序，每阶段可独立验收）

### 阶段 1：手动新局（解决最大缺陷）

- UI：长按重置按钮触发新局流程（短按保持原行为或弹确认）。
- CaptureProbeService：收到新局请求 -> 复用现有手牌识别流程（rank probe + 稳定候选）识别当前手牌 -> 成功后派发 NewSession + SelfHandLocked -> 会计归零；识别失败则保持原状态并提示未识别到手牌。
- 复用现有 SessionStore.replaceWithNewSession()；确保旧事件不参与新局会计（重放时从新 NewSession 开始）。
- 验收：长按重置后所有座位已出归 0；旧日志不再影响新局。

### 阶段 2：自己手牌差分记账（把装饰变成锚点）

- 每帧观测自己手牌张数（复用/强化 HandCardPositionDetector 的牌位链检测）。
- 自己手牌数减少 N -> 记录 SelfCardsPlayed(N)，正数累加 selfPlayedCount。
- 自己剩余显示 = 锁定手牌 - 自己已出（派生，仅显示）。
- 验收：自己出 3 张 -> 自己已出 +3，手牌差分驱动，不依赖牌面识别。

### 阶段 3：正数会计与守恒校验（把计数与识别解耦）

- GameReducer：OutsideCardsPlayed 只累加 cardCount（张数），牌面 rank 只做显示层猜测。
- 移除 clampTo 掩盖逻辑 -> 改为守恒校验：所有座位已出 + 自己剩余手牌 <= 198；违反 -> SessionPaused(NEW_GAME_UNCLEAR) 或冻结该座位事件，等待用户处理。
- 空手校准（增强，可选）：某座位手牌区变 0 -> 该座位本局已出应等于其初始手牌数（198 - 自己 - 其他座位），不符则把差值记为该座位最近一手。
- 验收：单元测试覆盖 rank 错但张数对、守恒违反触发暂停而非 clamp。

### 阶段 4（可选增强）：自动新局辅助

- 若手动重置体验不佳，再做自动检测：自己手牌数量突变为发牌手数 + 桌面已清空 -> 自动 NewSession。手动优先，自动为兜底，避免误判。

## 五、与旧方案（v4/v5）的区别

| 项 | 旧路线 | 本方案 |
|---|---|---|
| 新局 | 无概念，跨局累计 | 长按重置 = 手动新局（确定性） |
| 自己手牌 | 纯日志装饰 | 差分记账主锚点 |
| 会计方向 | 倒数（剩余=198-自己-已出） | 正数（已出从 0 累加） |
| 错误处理 | clampTo 掩盖 | 守恒校验暴露 + 暂停 |
| 计数依据 | 牌面识别结果 | 张数（与牌面解耦） |

## 六、风险与开放问题

1. 长按重置时手牌识别失败：重试一次；仍失败则保持原局并提示（不强制归零）。
2. 自己手牌张数在出牌动画期间可能短暂跳变：需要稳定窗口（复用 stableSamples 思路），避免差分误判。
3. 其他座位初始手牌数未知：空手校准依赖局末或所有已出+剩余=198 推导，先做守恒拦截，校准作为增强。
4. 大王/小王识别异常是独立问题，属于牌面层，本方案不阻塞；数量层先保证张数正确。
