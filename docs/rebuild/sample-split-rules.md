# 样本切分规则（整局粒度）

关联：`dataset-manifest.json`、方案第 5 节 Phase 0/Phase 5。

## 1. 切分单位

- 以**整局**为最小切分单位，不以帧或时间段切分。
- 一局 = 从新局开始（发牌/交贡/还贡/买 3 买 4 等前置转移之前）到结算完成。
- 同一次录制文件中含多局时，须先按局切分再分配集合。

## 2. 禁止相邻帧跨集合

- 时间上相邻的帧（同一录制片段、同一局、清桌前后过渡段）**不得**分属不同集合。
- 切分点只能落在整局边界：上一局结算画面结束后、下一局发牌开始前。
- 同一局的任何片段（含失败/暂停段）只能进入该局所属的唯一集合。

## 3. 集合用途与纪律

| 集合 | 用途 | 纪律 |
|---|---|---|
| dev | 开发调试、修 bug、验证状态机 | 可反复查看 |
| tuning | 调参、阈值标定、模型选择对比 | 可反复查看；禁止据其结果再改 dev 上已冻结的判定逻辑后不重跑盲测 |
| blind | 最终放行评估 | **独立牌局；禁止调参后回看**：一旦根据盲测结果修改了任何模型/阈值/状态机参数，该盲测集即作废，须换用从未参与过任何开发决策的新牌局重建盲测集 |

## 4. 其他约束

- 集合成员一经固化写入 `dataset-manifest.json`，移动成员须记录原因与日期（本文件追加变更记录）。
- 补录的新牌局优先补 dev/tuning，盲测集始终保留从未见过的素材。
- 每局标注：session、zone、start/stable/clear 时间、quantity、Rank、动画/遮挡/过牌标签（Phase 5 数据要求）。
